# X1-Yoga-Gen-3-Hackintosh-EFI
A Hackintosh EFI for the Thinkpad X1 Yoga Gen 3. Support up to Sequoia 15.5 (Tested it, worked). Latest release has some bug fixes.
For example now Airport WLAN and better Bluetooth Kexts has been added. There's now an ultra low power mode using CPUFriend.kext. Hibernation fully works. Used Audio Codecs from X1G6C (Microphone works now).

Whats working:
-WLAN
-Location Services
-Bluetooth
-AirPlay
-SleepState: 1,2,3

What's not working:
-AirDrop & Handoff
-Touch & Stylus
-IPhone Sync
-SleepState: 4 (After a long time when the LED on the back is blinking it goes off for some minutes and then It goes back on back to S1; will try to get it working)
